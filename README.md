# HBB_MiniProject_BioinformHer
 mini project successfully explored the evolutionary conservation of the Hemoglobin Beta (HBB) gene across twelve primate species using fundamental bioinformatics tools.

HBB Mini Project – BioinformHer Module 2

## 📌 Objective
To investigate the evolutionary conservation of the Hemoglobin Beta (HBB) gene across 12 primate species using BLAST, sequence alignment, sequence logo analysis, and phylogenetic tree construction.

## 🧪 Tools Used
- NCBI BLAST
- Clustal Omega / MUSCLE
- EMBOSS Needle
- Skylign
- MEGA X
- Jalview

## 📁 Files Included
- Report PDF: `HBB_MiniProject_NishaAbilashNair.pdf`
- Cleaned FASTA sequences: `hbb_project_clean.fasta`
- Aligned file: `HBB_aligned.meg`
- Tree & alignment screenshots

## 🧠 Summary
This project confirmed the high conservation of the HBB gene across primates and showed expected evolutionary relationships through phylogenetic analysis. Highly conserved regions reflect the gene’s critical biological role.
